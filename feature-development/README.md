Use it to take a new feature from the request to a merged pull request.

1. Research checks whether it is worth doing and ends the task when it is not.
2. Design writes how it will work. You approve it.
3. Plan breaks the design into the changes to make. You approve it.
4. Build implements the plan with tests and commits on the task's branch.
5. Code review on another agent approves the change or sends it back to Build.
6. Ship pushes the branch, opens a pull request and merges it once its checks pass.
