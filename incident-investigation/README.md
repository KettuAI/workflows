Use it after something went wrong in production or in a release, when you want the real cause and not a quick patch.

1. Gather evidence builds the timeline from logs, errors and recent changes, without touching production.
2. Root cause proves the cause by reproducing it and proposes a fix and its prevention. You approve it.
3. Fix starts with a failing regression test.
4. Review the fix on another agent checks it fixes the cause, not a symptom.
5. Postmortem writes a blameless summary with action items.
