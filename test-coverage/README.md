Use it to add tests where they matter instead of chasing a coverage number.

1. Find gaps ranks untested code by what a bug there would cost. You approve the list.
2. Write tests adds tests and proves each one fails when the code breaks. It never changes the code under test.
3. Review tests on another agent checks the tests are real, not tautological or flaky.

When a new test exposes a real bug, the task stops and asks you what to do; the bug is described, not silently fixed.
