Use it for a new screen or a redesign where you want to choose the look before anyone writes code.

1. Drafts makes three directions as a page you can open, in light and dark, from your project's own design tokens.
2. Pick a direction is yours: build one, with your changes in the note, or ask for new drafts.
3. Build implements it with every state.
4. Visual check runs the app and compares screenshots in light, dark, small and large windows with the draft.
5. Code review on another agent looks for bugs, missing states and accessibility problems.
