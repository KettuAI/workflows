Use it for a focused security review of a project or one part of it, such as an API, an upload feature or a plugin system.

1. Attack surface maps entry points, trust boundaries and the threats that matter, as a document.
2. Hunt looks for vulnerabilities along that map.
3. Verify checks every candidate as a skeptic on another agent, so the report holds only real problems.
4. Audit report writes the findings with severity and fixes for you to approve.
5. Decide is yours: fix them now or keep the report.
6. Fix and Review the fixes close the vulnerabilities with tests, reviewed on another agent.

Nothing is changed before you decide. Verification only runs small local tests and never touches real services.
