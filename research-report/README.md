Use it for any question that needs real research: choosing a library or vendor, understanding a market, a technical deep dive or a literature review. It works in any folder, not only code projects.

1. Scope turns your question into specific questions and the shape of the report. You approve it.
2. Evidence and Counterpoints research at the same time: one follows the main line, the other looks for what would change the answer.
3. Write the report weighs both and leads with the answer.
4. Fact-check on another agent opens the sources and checks every claim.

Research needs web access in the agents doing it.
